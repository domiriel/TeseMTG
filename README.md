# Interactions
## Filter Panel 
  - Filter charts by clicking on one of the filter options available
  - Can change the price used in the relevant charts(Alluvial and Scatterplot)
  - Reset Button that resets all the filters that are activated(even the ones that are not filter options in the filter panel)
  - Can Share and load filters(work in progress)
## Alluvial Chart
  - Can click on a node to only focus in the links that contain the node
  - Can click on a link to only focus in that link and the nodes that are part of it
  - Can double click on a node to activate the corresponding filter(e.g. Rarity)
  - Can double click on a link to activate the correspondig set of filters (e.g. Original Rare cards)

## Icicle Chart
  - By clicking on one of the rectangles (e.g. 1 Color, Black + Blue cards), it becomes the focus in the chart and zooms on it
  - By double clicking on a rectangle, it filters the others to only show cards from that subset

## Scatterplot 
  - By clicking on a dot, it highlights where it is in the other charts and it can be viewed in the drawer(multiple can be selected)
  - Can also zoom by clicking on a space without a dot, or scrolling with the mouse

## Line Chart
  - By clicking on a circle in any of the Line charts, it filters the other charts to only show cards from that year (multiple can be selected)

## Timeline View
  - By clicking on a set, it filters the other charts to only display cards from that set (multiple can be selected)
  - By clicking on a year label, it filters the other charts to only display cards from that year(multiple can be selected)
  - By clicking on a set type label, it filters the other charts to only display cards from that set type(multiple can be selected)

## Hidden Drawer
  - Displays the selected cards in the scatterplots
