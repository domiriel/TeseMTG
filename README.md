# Interactions
## Filter Panel 
  - Filter charts by clicking on one of the filter options available
  - Can change the price used in the relevant charts(Alluvial and Scatterplot)
  - Reset Button that resets all the filters that are activated(even the ones that are not filter options in the filter panel)

## Alluvial Chart
  - Can click on a node to activate the corresponding filter(e.g. Rarity)
  - Can click on a link to activate the correspondig set of filters (e.g. Original Rare cards)

## Icicle Chart
  - By clicking on one of the rectangles (e.g. 1 Color, Black + Blue cards), it becomes the focus in the chart and filters the others to only show cards from that subset

## Scatterplot 
  - By clicking on a dot, it highlights where it is in the alluvial chart(only in the rarity part) and in the Icicle Chart (TODO: make the card selected highlighted)

## Line Chart
  - By clicking on a circle in any of the Line charts, it filters the other charts to only show cards from that year (multiple can be selected) (TODO: make the circles in the other line charts to also become highlighted)

## Timeline View
  - By clicking on a set, it filters the other charts to only display cards from that set (multiple can be selected)
  - By clicking on a year label, it filters the other charts to only display cards from that year(multiple can be selected)
