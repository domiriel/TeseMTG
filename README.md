# Interactions
## Filter Panel 
  - Filter charts by clicking on one of the filter options available
  - Can change the price used in the relevant charts(Alluvial and Scatterplot)
  - Reset Button that resets all the filters that are activated(even the ones that are not filter options in the filter panel)

## Alluvial Chart
  - Can click on a node to activate the corresponding filter(e.g. Rarity)
  - Can click on a link to activate the correspondig set of filters (e.g. Original Rare cards)

## Icicle Chart
  - By clicking on one of the rectangles (e.g. 1 Color, Black + Blue cards), it becomes the focus in the chart and filters the others to only show cards from that subset
